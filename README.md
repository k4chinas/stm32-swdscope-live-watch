# stm32-swdscope-live-watch
(ENG) Live-watch STM32 variables over ST-LINK (SWD) without halting the core: log, plot, trigger and stream them. Browser UI, automatic DWARF type decoding, oscilloscope-style trigger, live write-back. No UART, no dependencies. 
(TR) STM32 değişkenlerini ST-LINK (SWD) üzerinden, çekirdeği durdurmadan canlı izle, kaydet ve dışa aktar. Tarayıcı arayüzü, DWARF ile otomatik tip çözümü, osiloskop tarzı tetikleyici, karta canlı değer yazma. UART ve harici paket gerekmez.
